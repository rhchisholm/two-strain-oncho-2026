# Simulation data files

This directory is used for raw and intermediate simulation outputs generated
by the full model-fitting and projection workflow.

These files are computationally intensive to generate and most are not included 
in the repository. They can be regenerated using the full analysis scripts
described in the main repository README.

Compact processed datasets required to reproduce the manuscript figures and
tables without rerunning the model simulations are provided in
`data_processed/`, `stability_data/`, and `tables/`.

The Rdata files in this folder are needed for the scenario analyses.
